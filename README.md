## 1. Индивидуальный дизайн

Приложение выполнено в виде визуального редактора структуры HTML-документа.

* Интерфейс разделён на две основные области:

  * дерево структуры HTML-документа
  * панель добавления и редактирования элементов
* Пользователь может добавлять:

  * HTML-контейнеры
  * текстовые узлы
  * изображения с компьютера
  * строки таблицы
* Для элементов можно назначать CSS-классы.
* В отдельной области отображается сгенерированный HTML-код.
* Для отображения структуры документа используется `TreeView`.
* Оформление интерфейса вынесено в отдельный файл `style.css`.

---

## 2. Обработка исключений в композите или выше

Для обработки ошибок используется собственное исключение `CompositeException`.

* Исключение возникает при некорректной работе со структурой документа.
* Обрабатываются следующие ситуации:

  * попытка создать контейнер с пустым именем тега
  * попытка создать пустой текстовый элемент
  * попытка добавить дочерний элемент в лист
  * попытка удалить отсутствующий элемент
  * попытка добавить пустой компонент
  * ввод пустого CSS-класса
* Листовые элементы не поддерживают добавление дочерних компонентов и выбрасывают `CompositeException`.
* В классе `Controller` исключения перехватываются и отображаются пользователю через `Alert`.

## 3. Использование ресурсного файла

В приложении используются ресурсные файлы, расположенные в каталоге `resources`.

* `editor-view.fxml` содержит описание графического интерфейса.
* `style.css` содержит оформление элементов JavaFX.
* `config.properties` используется для хранения параметров приложения.
* Из ресурсного файла загружаются:

  * корневой HTML-тег
  * тег основного содержимого документа
  * начальный статус приложения
* Использование `.properties` позволяет изменять настройки программы без изменения Java-кода.

---

## 4. Unit-тесты

Для проверки работы паттерна «Компоновщик» используются unit-тесты на основе JUnit.

* Проверяется генерация HTML для текстового узла.
* Проверяется генерация тега изображения.
* Проверяется работа HTML-контейнера.
* Проверяется вложение контейнеров друг в друга.
* Проверяется добавление CSS-класса.
* Проверяется генерация строки таблицы.
* Проверяется выбрасывание исключения при создании некорректного контейнера.
* Проверяется невозможность добавления дочернего элемента в листовой компонент.
